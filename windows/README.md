# 🪟 Nexus AI Studio — Windows Edition

Dedicated Windows Edition supporting both **Native Setup (No Docker required)** and **Docker Desktop Setup**.

## 🚀 Quickstart (PowerShell 1-Line Setup)

```powershell
irm https://raw.githubusercontent.com/kefe3/nexus/main/windows/install.ps1 | iex
```

## ⚡ Option 1: 1-Click Native Batch Launchers (No Docker Needed!)
1. Double-click **`Nexus-Windows-Installer.bat`** to install Python venv & setup shortcut.
2. Double-click **`Nexus-Windows-Start.bat`** to launch anytime!
3. Double-click **`Nexus-Windows-Stop.bat`** to stop.

## 🐳 Option 2: Docker Desktop Setup
```cmd
cd windows
docker compose up -d
```
