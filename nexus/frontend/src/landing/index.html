OPENAI UYUMLU API GATEWAY

Sınırsız API Anahtarı & RESTful API

Tüm yerel ve bulut AI modellerini standart OpenAI RESTful API formatında cURL, Python, Node.js ve LangChain ile kullanın.

1-Tıkla Sınırsız API Anahtarı Üret (cURL)

Terminalden anında yeni bir sınırsız Nexus API anahtarı alın:

curl -X POST https://nexus.oedge.xyz/api/apikeys/generate \ -H "Content-Type: application/json" \ -d '{"name": "Sınırsız İstemci Key"}'
cURL Chat Completion (OpenAI Uyumlu)

Nexus API Gateway üzerinden modellere istek atın:

curl https://nexus.oedge.xyz/v1/chat/completions \ -H "Authorization: Bearer nx-live-YOUR_KEY" \ -H "Content-Type: application/json" \ -d '{"model":"qwen2.5-coder:7b","messages":[{"role":"user","content":"Merhaba!"}]}'
Python OpenAI Kütüphanesi İle Kullanım

Standart openai Python paketi ile base_url değiştirerek sınırsız model erişimi:

from openai import OpenAI client = OpenAI( base_url="https://nexus.oedge.xyz/v1", api_key="nx-live-YOUR_KEY" ) response = client.chat.completions.create( model="qwen2.5-coder:7b", messages=[{"role": "user", "content": "Merhaba Nexus!"}] ) print(response.choices[0].message.content)
HIZLI BAŞLANGIÇ

Tek Komutla Başlayın

Sisteminizde hiçbir şey kurulu olmasa bile — tek satır yeter.

Linux & macOS

Docker dahil her şeyi otomatik kurar. Terminali açın ve yapıştırın:
