# Contributing to Nexus AI Studio

We welcome community contributions from developers worldwide!

## How to Contribute
1. Fork the Repository on GitHub.
2. Create a feature branch: `git checkout -b feature/amazing-feature`.
3. Commit your changes: `git commit -m 'Add amazing feature'`.
4. Push to your branch: `git push origin feature/amazing-feature`.
5. Open a Pull Request.

## Adding New LLM Providers
Add new providers in `backend/app/api/chat.py` and register the provider metadata in `frontend/src/js/providers.js`.
